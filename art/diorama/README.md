# Little Ages painted cartoon kit

Original Blender-authored historical buildings, foliage, resources, and villagers.
`little-ages-diorama-kit.blend` and the seven runtime GLBs are generated by
[`build-diorama-assets.py`](../../scripts/build-diorama-assets.py), using the
model definitions in [`diorama_art.py`](../../scripts/diorama_art.py).

- One Blender unit equals one world tile; roots are ground-centered.
- Stable roots: Shelter, Stockpile, Workshop, FoodCluster, WoodCluster, StoneCluster, Villager.
- Each asset uses one shared painted color atlas with baked ambient occlusion.
- Buildings use 1024px atlases; resources and villagers use 512px atlases.
- Static parts are joined; each villager is a single skinned mesh with rigid shoulder/hip weights.
- Idle, Walk, Carry, Gather, Build, Socialize, and Rest remain exported clip domains.
- Runtime clothing variation changes only the blue clothing regions of the atlas.
- Source procedural materials are reproducible and have no external art dependencies.

Regenerate with Blender 5.2+:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python scripts/build-diorama-assets.py
node scripts/optimize-diorama-assets.mjs
```

Install web dependencies first with `npm ci` in `src/LittleAges.Web`. The optimizer
uses those pinned tools for Meshopt geometry and WebP texture packaging, preserves
named animation tracks, validates every GLB, and updates the byte manifest.
Do not hand-edit runtime GLBs. The compressed kit is 1,105,956 bytes, below 5 MB.

Review in the web dev server at `/?art-slice`. This uses the real renderer with
isolated presentation fixtures; it is omitted from production builds.
